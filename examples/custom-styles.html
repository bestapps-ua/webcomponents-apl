APL Custom Styles & Tailwind

APL components expose className and style properties (stored under reserved -bestapps* keys). They apply Tailwind utility classes and raw CSS to the Shadow DOM .wrapper — visible in the editor/preview, but stripped from the exported APL document.

Tailwind classes are generated at runtime by Twind from cdn.jsdelivr.net. In the full editor (examples/index.html) edit these in the inspector's Custom Styles group. Requires an internet connection.
